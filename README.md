# 동영상 강의용 오토클릭 (VideoAutoClick)

인터넷 강의·법정의무교육·연수 등에서 **동영상 재생이 멈추면 자동으로 다음 버튼을 눌러주는** Windows용 오토클릭 프로그램입니다.

## 📥 다운로드 및 설치 방법
1. [VideoAutoClick-Setup-2.0.exe 다운로드](https://github.com/moonhouse-80san/free/blob/master/VideoAutoClick-Setup-2.0.exe) (약 75MB)
2. 내려받은 `VideoAutoClick-Setup-2.0.exe`를 실행해 설치한 뒤 **VideoAutoClick**을 실행합니다.
3. 프로그램이 실행되면 아래 순서로 설정합니다.
   - **대상창**: `창지정`을 클릭해 동영상이 재생되는 브라우저를 선택합니다.
   - **감지 영역**: 동영상 강의 영역을 `영역 드래그`로 지정합니다.
   - **단계별 이미지**: 한 차시가 끝나면 나타나는 버튼을 `단계별 이미지`로 등록합니다. (강의마다 끝 화면이 다를 수 있어 최대 3단계까지 등록 가능하며, 1번이 있으면 2·3번은 건너뜁니다.)
   - **감시 시작(`F8`)을** 누르면 강의가 끝날 때마다 자동으로 다음 단계로 넘어갑니다.

## ✨ 주요 특징
- **정지 감지 실행**: 정해진 시간마다 누르는 방식이 아니라 동영상 움직임이 멈출 때만 동작해 시간 낭비와 오동작을 줄입니다.
- **이미지 기반 클릭**: 클릭할 버튼 위치를 이미지로 지정(작은 영역 캡처 권장)해 오작동을 방지합니다. (좌표 추적도 지원)
- **다단계·순서 변경**: 여러 단계를 추가하고 마우스 드래그로 순서를 바꿀 수 있습니다.
- **접기 모드**: `접기`를 누르면 최소한의 정보만 띄워 둘 수 있습니다.
