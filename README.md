[설치 방법]

1. 내려 받은 VideoAutoClick-Setup-2.0.exe 실행해서 프로그램 설치

2. VideoAutoClick 실행

2. 동영상 정지 감지 오토클릭 프로그램이 살행되면 

대상창 : 창지정을 클릭해서 동영상이 재생되는 브라우즈를 선택 
동영상 강의 영역을 "영역 드래그로 지정"
한 차시의 강의가 끝나면 출력되는 버턴을 "단계별 이미지"로 등록합니다.
나타나는 강의의 끝 부분이 다를 수 있으므로 3단계 까지 이미지 등록 합니다.
참고로 1번 이미지가 존재하면 2,3번은 pass, 2번이 존재하면 3번은 pass.
"감시 시작(F8)를 누르면 동영상 강의가 계속 플레이 됩니다.  
프로그램의 용량이 75M 정도 되는 큰 파일입니다.
 

[특징]

1. 동영상의 움직임을 감지하여 멈추면 다음 클릭 동작 실행

2. 클릭할 위치를 이미지로 보여 줄 수 있어서 오동작 방지 - 다음 동작 이미지를 캡쳐할때 되도록이면 작은 범위를 캡처

3. 단계 추가를 통해서 여러 상항에 대처 가능

4. 단계를 마우스 드래그로 순서를 바꿀 수 있슴

5. "접기"를 누르면 최소한의 정보만 보임
