# 동영상 정지 감지 오토클릭 v2 (Windows 11)

## 동작 방식
이미지를 등록한 단계는 그 이미지가 화면에 보이면 바로 클릭하고 다음 단계로 넘어갑니다.
- 이미지 우선순위: 1번 > 2번 > 3번
  · 1번 이미지가 있으면 1번만 클릭하고 2·3번은 건너뜁니다.
  · 1번이 없고 2번이 있으면 2번만 클릭하고 3번은 건너뜁니다.
- 이미지는 감시 영역 안에서만 찾습니다. (프로그램 창 미리보기는 무시)
- 클릭 후에도 감시는 절대 자동 종료되지 않습니다. (F8로만 중지)
이미지가 없는 단계는 지정한 동영상 영역이 설정 시간(기본 5초) 멈춰 있으면 클릭하고,
화면이 다시 움직이면 다음 단계로 넘어갑니다. 1→2→3번 순서로 진행합니다.
3번 클릭이 끝나면 종료합니다. ("마지막 단계 후 1번부터 반복"을 켜면 계속 순환)

## 설치 / 실행
1. Python 3.10~3.12 설치 (설치 화면에서 Add Python to PATH 체크)
2. 압축을 새 폴더에 풀고 `실행하기.bat` 더블클릭 (처음 한 번 라이브러리 자동 설치)
3. exe로 만들려면 `build_exe.bat` 실행 → dist\VideoAutoClick.exe 생성
   (설정·이미지·로그는 exe와 같은 폴더에 저장됩니다)

## 사용 순서
1. ① 감시 영역: [영역 드래그로 지정] → 동영상이 재생되는 부분을 마우스로 드래그
   - [미리보기 새로고침]으로 영상이 제대로 찍히는지 꼭 확인하세요.
2. ② 1~3번 단계 (필요한 만큼만 설정, 비워 두면 건너뜀)
   - [이미지 캡처]: 화면에서 드래그해 이미지 등록 / [파일 선택]: 저장된 이미지 불러오기
   - [좌표 지정]: 화면이 어둡게 바뀌면 클릭할 위치를 클릭
   - 이미지를 등록한 단계: 영상 움직임과 상관없이 그 이미지가 화면에 보이면 바로 클릭
     (좌표도 지정했으면 그 좌표를, 없으면 이미지 중앙을 클릭)
   - 좌표만 지정한 단계: 영상 영역이 정지했을 때 그 좌표를 클릭
3. ③ 설정 확인 후 [감시 시작] 또는 F8 (시작하면 창이 최소화됩니다)
4. 중지는 F8 (다른 창을 쓰는 중에도 동작). 완료/오류 시 창이 다시 나타나고 알림음이 납니다.

## 설정 설명
- 정지 판단 시간: 이 시간 동안 변화가 없으면 정지
- 화면 확인 간격: 화면 비교 주기 (0.3~1.0 권장)
- 움직임 기준(%): 영역에서 바뀐 픽셀 비율이 이 값 이상이면 움직임. 낮을수록 민감
  (영상에 시계·커서처럼 작게 깜박이는 게 있으면 값을 올리고, 정지를 못 잡으면 올려 보세요)
- 사용자 입력 대기: 내가 마우스/키보드를 쓰는 중이면 클릭을 미루고, 멈추면 클릭
- 클릭 후 재시도: 클릭 후 이 시간 동안 화면이 안 움직이면 다시 시도(최대 3회, 그래도 안 되면 중지)
- 이미지 일치도: 이미지 인식 엄격도 (기본 0.85, 인식이 안 되면 0.75 정도로)

## 병행 작업 시 주의
- 이 프로그램은 화면에 보이는 그대로를 캡처합니다. 감시 영역과 클릭 위치를 다른 창이 가리면
  오작동하므로, 영상 창은 가려지지 않게 두세요. (보조 모니터에 영상을 두는 것을 권장)
- 클릭은 실제 마우스 클릭입니다. 클릭 순간 마우스가 잠깐 이동했다가 원위치로 돌아옵니다.
- 영상 창 위치/크기를 바꾸면 영역과 좌표를 다시 지정해야 합니다.
- 보호된 영상(DRM)이나 하드웨어 가속 설정에 따라 캡처가 검게 나올 수 있습니다.
  미리보기가 검게 보이면 정지로 오인되므로 사용하지 마세요.
- 문제 확인용 로그: autoclick.log (프로그램 폴더)
- 사이트 이용약관이나 보안/출석 확인 절차를 우회하는 용도로는 사용하지 마세요.

## 폴더 구조
main.py            진입점

vac/capture.py     화면 캡처, 한글 경로 이미지 입출력
vac/detector.py    정지 감지, 이미지 찾기
vac/engine.py      단계 진행 상태머신
vac/overlay.py     드래그/클릭 지정 오버레이
vac/gui.py         화면(tkinter)
tests/             화면 없이 돌리는 로직 테스트 (python -m unittest discover -s tests -v)
